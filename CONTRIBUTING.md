# Участие в проекте

## Исправления словаря

В Issue укажите `id`, проблему и предлагаемый вариант. Для PR:

1. Прочитайте [процесс подготовки](docs/pipeline.md).
2. Исправьте русскую статью в `data/ru/part-*.jsonl`, сохранив элементы и порядок.
3. Выполните `npm run build:atlas` для обновления экспортов и данных приложения.
4. Запустите `npm run check:atlas`, `npm test`, `python3 -m unittest discover -s scripts/atlas -p 'test_*.py'`.
5. Объясните исправление; при необходимости приложите словарный или грамматический источник.

Не правьте только сгенерированный файл: сборка перезапишет такое изменение. Оригинальные англо-китайские экспорты при исправлении русского текста не меняются.

## Код

- Строгий TypeScript, функциональные React-компоненты, существующая архитектура без лишних зависимостей.
- Без аккаунтов и отслеживания; прогресс локальный.
- Русские подписи, ошибки, подсказки и доступные названия элементов. Английские учебные тексты остаются английскими.
- Проверяйте длинные строки, обе темы, ширину 375 px, клавиатуру.
- Перед PR: `npm test`, `npm run check:atlas`, `npm run build`.

## Новые материалы и ключи

Указывайте источник и лицензию. Для открытого словаря нужны права на распространение по CC BY 4.0; доступность файла в сети сама по себе их не подтверждает.

Не помещайте ключи API в Issue, PR, скриншоты, логи или репозиторий.

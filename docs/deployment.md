# Развёртывание

`npm run build` создаёт статический сайт в `dist/`. Сервер приложений и база данных не нужны.

После изменения переводов:

```bash
npm run build:atlas
npm run check:atlas
npm test
npm run build
```

## Подкаталог

```bash
ATLAS_BASE=/words/ npm run build
```

Размещайте весь `dist/`, включая `atlas/`, `sfx/`, `brand/`, `sw.js`, под одним базовым URL. Навигация использует хеш URL.

Пример для `dist/`, скопированного в `/var/www/words/` (директивы внутри блока `server`):

```nginx
root /var/www;

location /words/ {
    try_files $uri $uri/ /words/index.html;
    add_header Cache-Control "no-cache" always;
}

location ~ ^/words/(assets/|atlas/(img|thumb|audio)/) {
    try_files $uri =404;
    add_header Cache-Control "public, max-age=31536000, immutable";
}
```

`index.html`, `sw.js` и `atlas/index.json` должны проверяться при каждом обращении (`no-cache`), в том числе на CDN. Долгий неизменяемый кеш подходит для хешированных файлов в `assets/` и поставляемых медиа. Если заменяете медиа, меняйте их URL: прежнее имя с `immutable` может храниться год. Блоки `atlas/entries/` остаются с `no-cache` на HTTP-уровне; service worker хранит их по URL с ревизией содержимого.

## Кеш и голос

В производственной сборке service worker регистрируется после события `load`, чтобы установочный precache не конкурировал с первой загрузкой страницы. При установке он сохраняет страницу, её JS/CSS и шрифты, а также индекс словаря. После завершения установки приложение открывается без сети уже после первого посещения. Для этого дождитесь окончания первой загрузки; установка не завершится, если обязательный файл недоступен.

Страница и индекс проходят HTTP-ревалидацию (`no-cache`); при наличии ETag/Last-Modified неизменившееся содержимое можно использовать из HTTP-кеша после ответа 304; остальные просмотренные материалы кешируются. `npm run build:atlas` автоматически записывает SHA-256 блоков статей в `index.json.rev`. URL блоков содержит `?v=<rev>`, поэтому после правки переводов новый индекс не использует старые карточки. Не меняйте `index.id`: он связывает словарь с существующим прогрессом. Публикуйте согласованный комплект из одной сборки.

Прослушанная английская запись сохраняется целиком и доступна офлайн, в том числе для Range-запросов проигрывателя. Все изображения и записи заранее не скачиваются; медиакеш ограничен 1500 файлами, старые могут быть вытеснены. При сохранении нового индекса удаляются кешированные блоки других ревизий; при сохранении HTML — устаревшие ассеты с учётом ссылок на шрифты из текущего CSS. Кеши других приложений при активации не удаляются; кеши Word Atlas используют префикс `atlas-`. Прогресс `localStorage` сохраняется.

PWA требует HTTPS или локального адреса. Русские реплики используют голос устройства; доступность голоса и работа без сети зависят от системы. Английские записи не требуют системного голоса.

Изображения и аудио занимают сотни мегабайт. Проверка `npm run check:atlas` выявляет отсутствие файлов, указанных в битах `media`.

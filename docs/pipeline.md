# Подготовка и сборка материалов

## Русские переводы

Оригинал находится в `data/word-atlas.json`. Русские переводы подготовлены языковыми моделями по английским определениям/примерам и китайским пояснениям. Результаты — `data/ru/part-01.jsonl` … `part-12.jsonl`.

Для исправления найдите статью по `id`, измените перевод, сохранив порядок и число элементов `senses`, `ex`, `col`, затем выполните:

```bash
npm run build:atlas
python3 -m unittest discover -s scripts/atlas -p 'test_*.py'
npm run check:atlas
npm test
npm run build
```

Сборщик не обращается в сеть. Он объединяет русские поля с английским оригиналом, создаёт JSON/CSV, индекс и блоки статей. Пропуск статьи, дубликат, пустой перевод или китайский текст останавливают сборку до записи.

В индексе первое значение остаётся в `ru`, а все значения добавляются в столбец `search` после `media`. После записи блоков сборщик вычисляет их SHA-256 и записывает `rev` в индекс последним. Повторная сборка одинаковых данных сохраняет ревизию; любое изменение статьи меняет URL блоков в приложении. Вручную менять версию кеша после правки перевода не нужно. Запускайте только одну сборку данных одновременно и публикуйте все её результаты вместе; правила HTTP-кеша приведены в [развёртывании](deployment.md).

Реплики интерфейса хранятся русскими строками в коде и произносятся голосом устройства. Английские записи и иллюстрации сохранены из оригинала.

## Исходный конвейер автора

Скрипты оригинального проекта в `scripts/atlas/` создают англо-китайские исходники. Для исправления русского перевода они не нужны.

1. `.local/forge/headwords.json`: идентификаторы, слова и смысловые заметки; файл не входит в публичный набор. Конкретный первоисточник списка не указан.
2. `gen_text.py`: значения, два вида примеров, сочетания и подсказки по единому стандарту. Исходные заметки не должны копироваться в результат.
3. `gen_images.py`: иллюстрации по сцене первого примера.
4. `gen_word_audio.py`, `gen_sentence_audio.py`: английские записи через ElevenLabs.
5. `build_atlas.py`: первоначальные англо-китайские экспорты и данные приложения. После него русские данные восстанавливаются через `npm run build:atlas`.

Промежуточные результаты — в игнорируемой `.local/`. Ключи читаются из окружения или внешнего каталога настроек. Генераторы обращаются к внешним API; обычная сборка приложения и русских данных их не запускает.

## Проверки

Автоматически проверяются структура, полнота, порядок, ссылки, медиа и сохранность английских учебных текстов. Это не доказывает смысловую точность всех переводов или принадлежность слова определённому баллу IELTS. Для языкового исправления укажите конкретную статью и объяснение.

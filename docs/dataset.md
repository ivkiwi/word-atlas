# Формат словаря

## Русский JSON: `data/word-atlas.ru.json`

Массив статей в порядке изучения: CEFR от простого к сложному, темы внутри уровня перемешаны детерминированно.

| Поле | Тип | Содержимое |
| --- | --- | --- |
| `id` | string | Уникальный идентификатор URL и медиа, например `principle` |
| `w` | string | Английское слово |
| `uk`, `us` | string | Британская и американская транскрипции IPA |
| `senses` | `{pos, ru, en}[]` | Части речи, русские значения, английские определения |
| `ex` | `{en, ru}[]` | Бытовой пример и пример IELTS с переводами |
| `col` | string[] | `English phrase｜русский перевод` |
| `fam` | string[] | Однокоренные слова с локализованными частями речи |
| `syn`, `ant` | string[] | Английские синонимы и антонимы |
| `tip` | string | Русская подсказка с английскими учебными словами |
| `cefr` | `A1`…`C2` | Оценочный уровень сложности |
| `topic` | string | Постоянный машинный ключ одной из 19 тем |
| `note` | string | Примечание о стиле, написании или нежелательном употреблении; может быть пустым |

## Исходные переводы: `data/ru/part-*.jsonl`

Одна JSON-строка: `id`, массивы строк `senses`, `ex`, `col`, строки `tip`, `note`. Порядок и длина массивов совпадают с оригиналом. В `col` хранится только русский перевод; английскую часть берёт сборщик из исходника.

Сборщик `scripts/atlas/build_ru.py` проверяет полное покрытие идентификаторов, отсутствие дублей, размеры массивов, непустые переводы и отсутствие китайских символов. Английские поля копируются из оригинала, части речи локализуются при сборке.

## CSV: `data/word-atlas.ru.csv`

UTF-8 с BOM. Многозначные поля соединяются через ` | `, сочетания и словоформы — через ` ; `. Русские поля: `meanings_ru`, `example1_ru`, `example2_ru`, `tip_ru`, `note_ru`. `topic` — машинный ключ, `topic_ru` — название темы. Английские определения и примеры находятся в соседних столбцах.

## Данные приложения: `public/atlas/`

- `index.json`: `locale: "ru-RU"`; строки `words`: `[id, word, ru, ipa, cefrIndex, topicIndex, media]`.
- `entries/<n>.json`: полные русские статьи блоками по 100, в порядке индекса.
- `img/<id>.webp`: 512 px; `thumb/<id>.webp`: 256 px.
- `audio/uk/`, `us/`: произношение слов; `audio/ex/`, `ex2/`: первый и второй примеры.

Биты `media`: `1` — изображение, `2` — британская запись, `4` — американская, `8` — первый пример, `16` — второй. Покрытие медиа проверяйте по битам.

Идентификатор словаря остаётся `word-atlas-open`. Идентификаторы слов, порядок и ключи прогресса сохранены. Запросы русских JSON содержат метку версии, чтобы старый кеш китайских статей не использовался после обновления.

## Оригинальный набор

`data/word-atlas.json` и `word-atlas.csv` сохраняют исходную англо-китайскую схему с полями `zh`. Русский интерфейс использует `ru`. При исправлении русского перевода оригинал не меняется.

# Безопасность и конфиденциальность

## Где хранятся данные

В «Атласе слов» нет аккаунтов, серверного хранения прогресса, аналитики или отслеживания. Прогресс хранится в `localStorage` текущего браузера. В разделе «Мой прогресс» его можно экспортировать в JSON и перенести на другое устройство. При импорте поля проверяются; некорректные данные отбрасываются.

## Ключи доступа

Для работы приложения ключи API не нужны. Только исходные генераторы в `scripts/atlas/` обращаются к сервисам моделей. Они читают ключи из переменных окружения (`SUB2_BASE_URL`, `SUB2_API_KEY`, `ELEVENLABS_API_KEY`) или внешнего каталога `ATLAS_SECRETS`.

- Не храните секреты в переменных `VITE_*`: их значения попадают в браузерную сборку.
- Перед публикацией выполните `npm run pack:public`: команда экспортирует разрешённые файлы и проверяет их на ключи и личные пути. Автоматическая проверка не заменяет ручную.
- Если ключ утёк, отзовите или смените его у поставщика сервиса.

## Сообщить об уязвимости

Используйте приватный отчёт об уязвимости в GitHub: **Security → Report a vulnerability**, если он доступен в репозитории. Не публикуйте секреты и детали эксплуатации в открытых Issues.
